# Dentalink Mobile

Dentalink Mobile is a mobile application designed to support dental clinic services by providing patients with convenient access to essential features through their smartphones.

## Project Overview

This application was developed as an academic team project. My contribution focused on the development of the mobile application using Flutter.

## Features

- User authentication
- Dental appointment management
- Patient information
- Clinic service access
- Responsive mobile interface

## Tech Stack

- Flutter
- Dart
- Firebase / API (sesuaikan dengan yang dipakai)
- Android Studio
